# Olimpo Energy — site estático

Projeto web mantido como registro de desenvolvimento de uma interface institucional.

## Estrutura

- `index.html`: página inicial.
- `about.html`, `services.html`, `work.html`, `blog.html` e `contact.html`: páginas do site.
- `css/` e `sass/`: estilos compilados e fontes Sass.
- `js/`: scripts da interface.
- `images/` e `fonts/`: recursos visuais e fontes.
- `prepros-6.config`: configuração de ferramenta de desenvolvimento presente na versão original.

## Consultar localmente

Clone ou baixe o repositório e abra `index.html` no navegador. Para servir os arquivos por HTTP, com Python instalado:

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000`. Os arquivos CSS já presentes permitem consultar as páginas sem recompilar o Sass.
